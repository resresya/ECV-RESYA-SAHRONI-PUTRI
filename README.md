# E-CV — Resya Sahroni Putri

Website E-CV berbasis Streamlit dengan desain kreatif bernuansa **cream, terracotta, sage green, dan mauve** (bukan biru tua).

## File
- `app.py` — aplikasi website.
- `requirements.txt` — dependensi.
- `README.md` — panduan singkat.

## Upload ke GitHub
1. Unduh ZIP ini lalu ekstrak.
2. Buka repository GitHub.
3. Pilih **Add file → Upload files**.
4. Unggah `app.py`, `requirements.txt`, dan `README.md`.
5. Klik **Commit changes**.

## Personalisasi
- Ganti `email-kamu@example.com` di `app.py` dengan emailmu.
- Isi `url` pada daftar `SEMESTERS` dengan tautan KHS Google Drive masing-masing semester.
- Isi kolom URL pada daftar `CERTIFICATES` dengan tautan sertifikat yang sesuai.
- Pastikan Google Drive diatur ke **Siapa saja yang memiliki link dapat melihat**.
- Tambahkan `CV_Resya_Sahroni_Putri.pdf` di folder utama repository untuk mengaktifkan tombol Download CV.
- Opsional: tambahkan foto bernama `profile.jpg` ke folder utama repository.
- Periksa bahwa seluruh keahlian dan deskripsi pengalaman sesuai fakta sebelum publikasi.

## Deploy
1. Buka https://share.streamlit.io/ dan masuk dengan GitHub.
2. Klik **Create app**.
3. Pilih repository dan branch `main`.
4. Set main file path menjadi `app.py`.
5. Klik **Deploy**.
